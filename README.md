# Youtube-CLI-Windows-Downloader
Bat files for downloading content of Youtube.

Usage:

download-video <optional-quality> url
download-song url


url should remove everything after the second "?", as well as the "?" itself.
e.g.
download-video 480 https://www.youtube.com/watch?v=OWfSJfftDvU

bad example:
download-video 480 https://www.youtube.com/watch?v=OWfSJfftDvU?pp=jjKHsHfsfs
